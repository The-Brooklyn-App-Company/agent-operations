# Return to desk

`<kit>`: two levels above this skill's real path.
Stop if it does not resolve.

1. Read `<kit>/docs/continuity.md#records`.
2. Read the backlog, the journal since the human left, the return list and
   the inbox.
3. Run `<kit>/scripts/status.sh` for what is running and what is stuck.
4. Search the conversation for the human's own words on each topic before
   presenting it as new.
5. Fill `<kit>/templates/packets/catch-up.md`: decisions first, each with a
   recommendation.
6. List only the unblocks the human must do themselves, with exact steps.
7. Give each claim its stage and evidence.
8. Keep it to one screen; link the rest.
9. After the human answers, record decisions in the journal and update the
   backlog.
